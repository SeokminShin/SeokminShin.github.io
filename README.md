# seokminshin.github.io

GitHub Pages user site for `seokminshin.github.io`. It holds two files:

| File | Purpose |
| ---- | ------- |
| `index.html` | Redirects the domain root to the research portfolio at [`/portfolio/`](https://seokminshin.github.io/portfolio/) |
| `robots.txt` | Serves the domain-root robots.txt and advertises the portfolio's sitemap |

The portfolio itself lives in [SeokminShin/portfolio](https://github.com/SeokminShin/portfolio).

## History

This repository previously held an unfinished 2024 React homepage, copied from
another researcher's site template. Because GitHub Pages publishes this
repository's root directly rather than a build output, that copy was being
served publicly — including the original author's CV, photo and publication
data, and their name in `public/manifest.json`. It was removed in full.

Keep this repository to just the two files above. Anything committed here is
published at the domain root.
